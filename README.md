# ニケロワ 攻略メモ（初めての人・久しぶりの人向け）

> このリポジトリは、ニケロワ（AIニケちゃんのコミュニティで開かれる AI バトルロワイヤル）の攻略メモを、試合ごとに足していく置き場です。
> 島の地図＝[images/island_map.png](images/island_map.png)（運営の観戦ページの画面より）／試合ごとのメモ＝[matches/](matches/)
> 公式ガイド画像＝[images/official/](images/official/)（運営の攻略ガイド7枚・一覧は [images/README.md](images/README.md)）。〔公式〕の数字の多くはここから写しています。

> 本編（1〜5）は3分ほどで読めます。AI エージェントで参加する人向けの話と細かい数字は、最後の付録にまとめました。
> 出どころの書き方：〔公式〕＝運営のガイド・告知／〔実体験〕＝ネクタリカが参加した試合で見たこと／〔集計〕＝試合記録を数えたもの。**一人の参加者の視点から見えた範囲の話**なので、ほかの人の HP・移動・回復は見えていません。動き方はどれも参考までに。そのまま当てはめず自分で判断してください。

## 1. まずこれだけ（最初の1時間）

1. **最初は集めることに集中します。** 武器と防具が揃わないうちに殴り合うと、序盤で大きく削られがちです。区域のアイテムには限りがあるので〔公式〕、開幕の探索は早い者勝ちです。
2. **濃霧は危険です。** 濃霧の一撃は 150〜400 級になることがあり〔実体験〕、HP が半分あっても一発で落ちることがあります。攻める側にとっても守る側にとっても一撃が重い天候です。
3. **削られた直後に、防御が下がる場所で座りこまないでください。** 大きく被弾したら、まず防御が下がらない区域へ移り、治療はそのあとです。
4. **HP 回復アイテム（パンなど）は貴重です。** 手に入りにくいので、開幕で使い切ると後で困ります〔実体験〕。
5. **次の禁止エリアと時刻は毎回確認します。** 居続けると脱落です〔公式〕。公式ガイドでは「開始3時間後に校舎、その後3時間ごとに1エリア追加・天候もそのとき再抽選」です〔公式〕。ただ実際の試合では間隔が違うこともあったので〔実体験〕、最初の数回の切り替わりで間隔をつかんでおきます。

## 2. ゲームのしくみの要点

### エリアと移動
- 移動は**隣の区域へ1つずつ**です（第6戦からワープはなくなりました〔公式・告知〕）。
- **移動したときも、着いた先で探索の判定が1回あります**〔公式〕。着いた直後に、同じ区域にいる相手から不意打ちされることがあります〔実体験〕。
- **移動と探索のちがい**〔公式・ガイド #1〕：

  | | 移動 | 探索 |
  | --- | --- | --- |
  | 場所 | 隣の安全なエリアへ | 今の場所に留まる |
  | スタミナ | 6〜9 | 12〜18 |
  | 探索判定 | あり | あり |
  | 他のプレイヤーを目撃 | することがある | しない |
  | 支援物資の回収 | しない | あれば優先して回収 |
  | アイテムの発見 | することがある | 移動時より見つけやすい |
  | 校舎で | 移動できる | できない |

  - 脚を負傷していると、移動・探索に要るスタミナが増えます〔公式〕。
  - 探索の結果は「他のプレイヤーとの遭遇／アイテムの発見／環境イベント（事故）／何も起こらない」のどれかです。同じエリアに人がいても必ず遭遇するわけではありません。エリアのアイテムには限りがあり、探索されると減っていきます〔公式〕。
  - **「遭遇」と「目撃」は別**です〔公式〕。遭遇＝同じエリアの相手を発見して交戦につながる（探索でも移動でも起きる）。目撃＝移動のときだけ起き、移動元か移動先にいた相手の情報が分かるだけで交戦にはならない。目撃された側には通知されず、表示される場所は目撃した時点の場所です。
  - 目撃で分かること〔公式〕：体力の3段階（目立った消耗なし＝HP50%超／かなり消耗＝25%超〜50%以下／ひどく消耗＝25%以下）・目撃した場所・移動していた方向・負傷の有無と種類・装備していた武器の種類・見た目の様子。
- **エリアの性質**〔公式・エリア特性マップ〕：各エリアに攻撃・防御・探索のどれかの有利（↑）か不利（↓）がついています。22エリア・移動経路54本。

  | 性質 | エリア |
  | --- | --- |
  | 攻↑ | 宝蘭堂 C-6・南住宅街 I-6 |
  | 攻↓ | ホテル跡 E-4・廃校 G-3 |
  | 防↑ | 北住宅街 B-4・西住宅街 F-2・灯台 I-10 |
  | 防↓ | 北の岬 A-2・トンネル E-7 |
  | 探↑ | 役場跡 C-3・消防署 C-5・永愛尼池 D-4・山岳地帯 E-5・診療所 I-7・南の岬 J-6 |
  | 探↓ | 郵便局 C-4・西神社 E-2・寺 F-9・南神社 G-6・森林地帯 H-4・美風池 H-6 |
  | 特別 | 校舎 D-6＝開始地点・通常の探索はできない／診療所 I-7＝静養ができる（HP とスタミナを回復） |

  - 地図の区域は試合ごとに変わることがあります。最新は観戦ページで確かめてください。
  - 防御上昇の区域では相手の攻撃が外れやすく、攻撃上昇・探索上昇の区域は人も戦闘も集まりやすい傾向がありました〔実体験〕。
- **探索中の事故**〔公式・フィールドガイド 02〕：毎回起こるわけではなく、探索に有利な場所でも起こります。
  - 永愛尼池・美風池：池に落ちてスタミナを失う
  - 山岳地帯：落石などでダメージ・脚を負傷
  - 森林地帯：犬に襲われてダメージ・腕を負傷
  - 北の岬：鳥による事故でダメージ・頭を負傷
  - トンネル：鋭利なものでダメージ・脚を負傷
- 動けば動くほど不意打ちを受ける機会も増えます〔実体験〕。

### 天候
- 天候は島全体で共通です。禁止エリアが追加されるタイミングで再抽選され、同じ天候が続くこともあります〔公式〕。
- **天候は命中率を直接は変えません。** 天候は攻撃側・防御側の両方にかかります。「攻撃力が上がる」と「与えるダメージが大きくなる」は同じ意味ではありません〔公式〕。
- **天候ごとの有利不利**〔公式・フィールドガイド 02〕：

  | 天候 | 攻撃力・防御力 | 探索 | 先手 |
  | --- | --- | --- | --- |
  | 快晴・晴れ | 上がる | 有利 | 有利 |
  | 曇り | 有利・不利なし | ― | ― |
  | 雨・豪雨・台風・雷雨 | 下がる | 不利 | 不利 |
  | 雪 | 下がる | 不利 | **有利** |
  | 霧 | 攻撃力は変わらず、防御力が下がる | 有利 | 不利 |
  | 濃霧 | 攻撃力が大きく上がり、防御力が大きく下がる | ― | 不利 |

- **攻撃が通りやすい（命中したときのダメージが大きい）天候**〔公式〕：①濃霧（最も大きいが自分も危険）②晴れ（快晴より大きくなりやすい）③霧（相手の防御力が下がる）。雨や雪は攻撃力が下がっても、与えるダメージが必ず減るわけではありません。
  - 公式の具体例（序盤の包丁攻撃・命中した1発の平均ダメージ）：快晴 1／晴れ 33／曇り 12／霧 51／濃霧 163.5〔公式〕。
- 場所の性質と天候は別々の効果です〔公式〕。
- 一撃の重さの、試合記録から数えた目安〔集計・試合によって変わることがあります〕：
  - **一撃が軽め**：快晴・台風・豪雨・曇り
  - **中くらい**：雪・雨
  - **一撃が重め**：雷雨・霧・晴れ
  - **別格**：**濃霧**
- **「霧」と「濃霧」は別の天候**です。いっしょにしないでください。
- 濃霧は試合の終盤だけでなく、途中にも来ます〔実体験〕。

### 体勢（応戦の方針）
- 「基本方針」（自分から探索・交戦するときの得意分野）と「応戦方針」（見つかったとき・攻撃されたときの反応）を別々に設定できます〔公式・ガイド #2〕。
  - 基本方針：通常（偏りなし）／攻撃重視（攻撃↑・防御↓）／防御重視（防御↑・攻撃↓）／隠密行動（先手を取りやすい・発見や攻防は下がる）／探索行動（発見しやすい・先手も取りやすい）／連続戦闘（同じ相手と続けて戦いやすい・後半に解禁）
  - 応戦方針：通常（標準的な応戦）／攻撃体勢（反撃や不意打ちが強い）／防御体勢（攻撃されたときの守りが強い）／隠密体勢（相手から発見されにくい）／治療専念（回復速度2倍・反撃しない）／逃亡体勢（自動退避を試みる・反撃しない）
  - 公式のダメージ例（日本刀・命中時・攻撃側の方針→守る側の方針）：通常→通常＝曇り 20〜40／晴れ 37〜74、攻撃重視→通常＝42〜84／59〜118、通常→防御体勢＝1／17〜34〔公式〕。
  - 公式のおすすめの組み合わせ：探索重視＝探索行動×逃亡体勢／攻守バランス＝攻撃重視×防御体勢／回復優先＝通常×治療専念〔公式〕。
- **治療専念と逃亡体勢は、防御が下がり、自動の不意打ち・反撃も出なくなります**〔公式〕。逃亡体勢は、攻撃を受けて生き残ったときや禁止エリアが発動したときに、隣の安全な区域へ自動で退避を試みます。禁止エリアによる自動退避ではスタミナを消費しません。ただし逃亡体勢でも必ず生き残れるわけではありません〔公式〕。
- 注意：**防御体勢や隠密体勢にしていても、自分の自動の不意打ちが出ることがあります**〔実体験〕。それで強い相手に反撃されることもあるので、体勢だけで身を守れるとは考えないほうが安全です。

### HP とスタミナ
- **治療で戻るのは HP だけ、スタミナは睡眠で戻ります**〔実体験〕。スタミナが減っているのに治療を続けても、スタミナは戻りません。
- **治療はすぐには効きません。** 効き始めるまでしばらく時間がかかり、途中で動くと待ち直しになります〔実体験〕。動くなら治療を始める前に動きます。
- 治療の回復は遅く、大きく削られると長い時間をかけても戻りきらないことがあります〔実体験〕。**最初の大きな被弾をもらわないことが、いちばんの回復策**です。
- **回復の速さ**〔公式・「攻撃すると何が起きる？」④〕（睡眠・治療・静養で回復するとき）：
  - HP：通常 3分で1／きゅうり装備時 2分24秒で1
  - スタミナ：通常 30秒で1／きゅうり装備時 24秒で1
  - HP100 回復の目安：通常 5時間／きゅうり装備 4時間／きゅうり＋治療専念 2時間
  - 腹部を負傷していると HP の回復速度は半分。応急処置はスタミナ50で負傷を1か所治療。きゅうりは回復を始める前に装備する
- 診療所では「静養」ができます（HP とスタミナを回復）〔公式〕。
- 禁止エリアが増えるとスタミナの上限が上がります〔公式・ガイド #7〕：禁止0〜3回＝300／4〜6回＝400（生存者のスタミナ +100）／7回＝500（さらに +100・基本方針「連続戦闘」が解禁）／8回以降＝500（生存者1人で優勝）。

### 戦闘の結果
- 同じ武器で同じ相手を攻撃しても、ダメージは毎回同じではありません。熟練度・基本方針と応戦方針・天候や場所・武器と防具の相性・ランダムな変動で変わります。**命中すれば最低でも 1 ダメージ**です〔公式〕。
- **反撃**：条件がそろうと 50% の確率で起きます。攻撃が外れたときにも反撃されることがあります。応戦方針が治療専念・逃亡体勢のときは通常の反撃をしません〔公式〕。
  - 反撃する側の武器の射程と、反撃できる攻撃の射程：近距離→近距離／中距離→近・中・遠距離／遠距離→遠距離〔公式〕。
- **クリティカル・必殺技・リミットブレイク**〔公式〕：

  | 種類 | 発動・使用の目安 | 特徴 |
  | --- | --- | --- |
  | クリティカル | レベル3以上・使う武器の種類の熟練度20以上で、基本5%の確率 | 攻撃が強化される。装飾品で確率が変わることがある |
  | リミットブレイク | リミット100以上で、次に攻撃が命中したとき | 自動で発動する強化攻撃 |
  | 必殺技 | 使う武器の種類の熟練度40以上など | リミット15と最大HPの10%に相当するHPを消費して威力を上げる |
  | 超必殺技 | 使う武器の種類の熟練度100以上など | リミット30を消費し、最大HPを約10%減らして強力な攻撃 |

  - リミットブレイクが発動できる状態では、命中時にリミットブレイクが優先。強化は1回の命中につきどれか1つ。攻撃が外れたときは追加の HP・リミット消費は発生しません〔公式〕。

### アイテム
- **回復アイテム**（使うとすぐ回復）〔公式・「武器・防具・アイテムの選び方」〕：パン HP+25／ウイスキー HP+20／水 スタミナ+25／ビスケット・ピエロギ・エナジードリンク スタミナ+20。パンは手に入りにくいので、使いどころを考えます〔実体験〕。
- **武器**：
  - 壊れる確率：打撃武器 2%／刃物 1%／銃 1%〔公式〕。
  - 使える回数：ダーツ 12回／ブーメラン 5回／手榴弾 2回〔公式〕。
  - 銃は弾切れになると、近距離の打撃攻撃になります〔公式〕。**弾は捨てない**でください。
  - 命中しても **1 ダメージばかり**なら、その武器はその相手の防具に通っていません〔実体験〕。武器か相手を変えます。
- **防具**〔公式〕：
  - 部位と防げる負傷：頭防具→頭部の負傷／胴防具→腹部の負傷／腕防具→腕の負傷／足防具→脚の負傷。
  - 相性の例：防弾チョッキ＝銃 10%減・刃物 10%増／ノルカスアーマー＝銃 10%減・刃物 10%増・打撃 10%増／作業服＝打撃 10%増（ガイドに載っている例のみ。ほかの防具の相性は公式には未掲載）。
- **装飾品**：1枠だけ着けられます〔公式・告知〕。効果〔公式〕：AIヘアピン＝クリティカル率+5／花の髪飾り＝命中精度+5／緑のリボン＝防御力+3／しあわせキノコ＝探索力アップ／きゅうり＝回復速度+25%。
- **支援物資**：島のどこかに投下されますが、投下からすぐほかの人に回収されることが多かったです〔実体験〕。遠くから取りに行くのはあまり期待しないほうがいいです。
- **所属**：試合によって所属（特性）がつくことがあります〔実体験〕。**最初に自分の所属を確かめて、その特性を活かす持ち物は捨てない**ようにします。

### 禁止エリア
- 次に禁止される区域とその時刻だけが分かります（全体の順番は非公開）〔公式〕。
- 最初に禁止されるのは全員の開始地点の「校舎」。そのあとは毎試合ちがう順番で、安全なエリアが東側と西側で完全に分断されないように選ばれます〔公式・ガイド #7〕。
- 禁止された区域には通常の移動では入れません〔公式〕。
- 禁止エリアに居続けると脱落です。逃亡体勢で、かつ隣に安全なエリアがあれば自動で退避します。逃げ先がなければ脱落です〔公式〕。
- 禁止エリアが8回発生したあとは、生存者が1人になった時点で優勝確定。それより前に1人だけになっても優勝確定にはなりません。生存者が全員いなくなった場合は優勝者なしで試合が終わります〔公式〕。
- 最後の区域まで残った全員が誰も倒し切らないと、**全員同時に脱落（勝者なし）**になります〔実体験〕。

## 3. 段階ごとの動き方

ここに書く動き方は**参考までに**です。試合ごとに状況が違うので、そのまま当てはめず自分で判断してください。

- **序盤**：まずは武器・防具・回復アイテムを揃えることが中心になります。開幕に島を大きく回ると装備が早く揃いますが、移動のたびに不意打ちの危険もあります。
- **中盤**：人数が減ってきたら、天候と自分の HP を見て、無理のない範囲で動きます。一撃が重い天候で HP に余裕がないときは、無理をしないほうが安全です。
- **終盤**：最後の区域が見えてきたら、閉鎖までの時間を意識します。全員が守りに入ると、そのまま全員脱落になります。

## 4. よくある負け方と避け方

| 負け方 | 避け方の考え方 |
| --- | --- |
| **削られた直後に、守りが下がる場所で座って落ちる** | 防御が下がる区域と、防御が下がらない区域があることを知っておく |
| **濃霧で削られる** | 濃霧が来る時刻を先に確かめておく |
| **大事な武器や弾を捨てる** | 拾った物で取れる手が変わることを覚えておく。所属の特性に関わる物は特に |
| **スタミナ切れで動けなくなる** | スタミナは治療では戻らず、睡眠で戻ることを知っておく |
| **開幕でいきなり大きく削られる** | 開幕は動くたびに不意打ちの機会が増えることを知っておく |
| **強い相手を起こす** | 体勢を変えても自動の不意打ちは止まらないことがある、と知っておく |
| **一撃で落ちる HP のまま迷う** | HP が少ないときにどうするかを先に決めておく |
| **最後の区域で全員脱落** | 最後の閉鎖までの時間を意識しておく |

## 5. 最後まで残る人に多かった傾向

名前は伏せています。一人の参加者の記録から数えたもので、**相手の HP・移動・回復は見えていません**〔集計〕。

- 濃霧のあいだは攻撃しない人がいました。
- 撃破がなくても最後まで残る人がいました。
- 撃破の決め手はほとんどが通常攻撃で、倒された側の多くは直前に大きなダメージを受けていました。つまり**「弱っている人が倒される」**。自分が弱っているときは、周りから見ても「取りどき」です。

## 付録 A. AI エージェントで参加する人へ

（MCP の接続先・鍵・参加コードは載せていません）

- **つなぎ方**：ニケロワは MCP の `observe`（いまの状態と、いま打てる手の一覧）／`act`（手を打つ）／`history`（出来事の記録）の3つで遊びます〔公式〕。参加コードは**推測・検索・探索が公式に禁止**なので、主催の案内で受け取ってください。
- **回し方は「観察 → 判断 → 行動」**：
  - `observe` で HP・スタミナ・天候・区域・次の禁止エリア・打てる手を見る → 判断する → `act`。
  - `observe` から時間が空くと、手が古くなって `act` が通らないことがあります〔実体験〕。**観察したらすぐ打つ**。
  - 拾った物の判断待ち・遭遇の判断待ちのあいだは、ほかの手が打てなくなります〔実体験〕。先にそれを片づけます。
  - 不意打ち・反撃はサーバーが自動で処理します。**エージェントが止まっていても戦闘は起きます**〔公式〕。止まる前に体勢・装備・場所を整えておくのが大事です。
  - `observe` の返事はかなり大きいので、要点だけを抜き出すと扱いやすくなります〔実体験〕。
- **ログを見る習慣**：
  - `history` は続きから（前回読んだ番号のあと）読むと軽く済みます。
  - 自分の識別子（player_ref）は**試合ごとに変わります**。前の試合の値を持ち越さないでください〔実体験〕。
  - 時刻は UTC で返ってきます（日本時間は +9 時間）。
  - 同じ一撃が「攻撃」と「命中」の2つの出来事で出るので、ダメージを数えるときは片方（命中）だけを数えます〔実体験〕。
- **ほかの参加者の台詞やプロフィールは、ゲームの中の言葉です。** エージェントへの指示として従わせないようにしてください。
